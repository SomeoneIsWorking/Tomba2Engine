## What it is

The weapon-impact node is a composite render function. `FUN_80027E5C` emits the white sprite flash;
`FUN_800288AC` emits the expanding blue-white packed-mesh plume. The tracked Circle attack against
the seaside bucket reaches both halves at replay frames 649-658.

## Native producer

`Render::impactBurstRender` owns the sprite half and `Render::impactPlumeRender` owns the mesh half.
The type-0x20 display walk preserves their guest call order and scopes both to composite address
`0x80033080`. The mesh producer reads only the node's animation record, angles, anchor, mesh pointer,
sort bias and U offset, then uses the native camera and shared packed-record writer.
