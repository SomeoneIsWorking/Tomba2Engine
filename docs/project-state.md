Structure-only pass (no behaviour change): the `libsnd` sequencer split from one 2,768-line file into
seven responsibility-named translation units (`Sequencer` stays one class, now in `tomba::audio`) and
the A00 zoned-attacker cluster split from 1,496 lines into three (now `tomba::ai::ActorZonedAttacker`),
with the shared per-channel lens and the guest ABI vocabulary each in one private header;
`docs/codemap.md` rewritten with per-directory ownership and the per-frame ownership chains. Verified
by code-line multiset equality against `HEAD` after the identifier remap, identical override-declaration
sets, `ctest` 23/23, and a headless `tools/live_play.py` run reaching free roam with the player MOVED.

Second structure pass: `tomba::camera::LookAngleBuilder` and `tomba::player::ActorInteraction` extracted, so `cutscene_camera.cpp` and `actor_tomba.cpp` drop below the 1,200-line cap; verified by code-line equality with `HEAD`, 23/23 ctest and a live run reaching gameplay.

Fourth structure pass, Tomba! 1: `titles/tomba1/game/core/` split by concept into `entry/` (process entry, the per-Core `Context`, `Tomba1Runtime`), `boot/` (native boot prefix, synchronous CD startup, the platform HLE/DMA sync plan), `frame/` (the finite frame transaction and the stream field turn), and `task/` (the three-record guest task table and its bounded cross-field resume), with `game/render/` unchanged beside them; `game/app/` and its README folded into `entry/`. One real policy defect fixed: `platformHlePlan()` held its table in a function-local `static`. The first attempt removed the `static` but returned a reference to a function-local aggregate, which Clang caught as `-Wreturn-stack-address` — a dangling table on every call. It is now a namespace-scope `const` in an anonymous namespace, initialised once at load, with no function-local static. Tomba! 1 was already fully namespaced (`tomba1::`) with no mutable globals; verified by `ninja -j2` on both products, `ctest` 23/23 including the two Tomba! 1 targets and `tomba_cpp_policy`, and a live run reaching gameplay with the player MOVED to the same 6000.285 and 0 faults as the baseline.

`tools/live_play.py` no longer couples to the source layout. `verify_address_owners()` pinned each guest address to one hard-coded owner FILE, so moving an owner between concept directories reported a disagreement about an address that had not moved — it broke twice in this batch alone. It now resolves each address by VALUE across the first-party tree, requiring the literal to be BOUND to a name (`NAME = <address>`, comment lines excluded) and reporting every declaring symbol as evidence. A move is no longer a disagreement; a renamed or deleted constant still is. Proved in both directions: 5/5 with no disagreements on the current tree, and a synthetic `0x0BADF00D` entry is correctly refused.

Third structure pass: `game/core/` (42 files) split by concept into `entry/` (process entry and the measured title facts), `engine/` (the stage driver and its seven parts), `frame/` (the per-frame turn), `overrides/` (catalog, registration, guest-call conventions), `debug/` (dev warp, dev areas, AutoDrive, REPL, verification counters), `hle/` (libapi) and `assets/` (Asset, Str). The `tomba::legacy` compatibility shim is gone: `grep -rn 'tomba::legacy' external/psxport` is empty and its only two readers were this title's own `TombaRuntime` constructor and one test, so both now call `tomba::title::measuredConfig()` / `tomba::title::hooks()` (`game/core/entry/title_facts.h`). `TOMBA_CPP_POLICY_CAPS` is now empty — `game/scene/demo.h=87` was an exception to the 1,200-line default that bought nothing but an obligation to ratchet on every edit. Of the near-cap files only `script_interp.cpp` (1,196) had a real sub-concept: `script_interp_entry.cpp` now owns "which entry is current and where does the cursor go next" while `script_interp.cpp` keeps the dispatch loop and the opcode bodies; `demo.cpp`, `render_walk.cpp` and `perobj_billboard.cpp` are each already one cohesive concept and were left alone. Verified by exact code-line multiset equality with `HEAD` for all 41 moved core files (only the three intended shim edits differ) and for the interpreter split, `ctest` 23/23 with `tomba_cpp_policy` reporting 0 explicit caps, and a live run reaching gameplay with the player MOVED to the same 6000.285 and 0 faults as the pre-change baseline.
