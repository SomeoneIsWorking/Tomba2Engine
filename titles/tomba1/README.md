# Tomba! (`SCUS_942.36`)

Planned first-game target in this repository. It will have its own game seam and native ownership;
it does not share `game/` with Tomba! 2. The title already runs at 60 fps, so its enhancement scope is
**widescreen only**: its future runtime must not install Tomba! 2's interpolation, frame-history,
camera/object lerp, or any prerequisite that exists only to synthesize intermediate frames.

This is a title policy, not an implementation claim. `SCUS_942.36` is the canonical USA title key;
no Tomba! 1 executable substrate, runtime seam, or widescreen producer has been implemented yet.
