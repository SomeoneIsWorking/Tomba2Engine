# Tomba! (`SCUS_942.36`)

Planned first-game target in this repository. It will have its own game seam and engine ownership;
it does not share `game/` with Tomba! 2. Its enhancement scope is **widescreen only**: its future
runtime must not install Tomba! 2's interpolation, frame-history, camera/object lerp, title-native
renderer, native graphics producers, or any prerequisite that exists only for those systems.

This is a title policy, not an implementation claim. The title exposes no 60fps or native-rendering
option. `SCUS_942.36` is the canonical USA title key; no Tomba! 1 executable substrate, runtime seam,
or widescreen producer has been implemented yet.
